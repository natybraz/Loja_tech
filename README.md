# TechStore Database (`loja_tech`)

Projeto prático de modelagem relacional, manipulação de dados e automação de rotinas em **MySQL**, desenvolvido no **MySQL Workbench**.

---

 Objetivo

Simular o banco de dados de um e-commerce de eletrônicos (**TechStore**), aplicando conceitos fundamentais de SQL:
* Criação de esquema relacional com chaves primárias, estrangeiras, colunas calculadas e constraints.
* Consultas de filtragem, ordenação, agregação e junção de tabelas (`INNER JOIN`).
* Desenvolvimento de *Stored Procedures* com parâmetros `IN` e `OUT`.
